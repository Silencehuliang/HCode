# 项目指令文件以 HCODE.md 优先,回退到 CLAUDE.md

我们读根目录的 `HCODE.md`;它不存在时回退读 `CLAUDE.md`,再回退 `AGENTS.md`。一个仓库可以同时存在多份 —— `HCODE.md` 优先,并且**启动时会报出实际生效的是哪个文件**,而不是静默地解决优先级。

读一个竞品的文件名是刻意的。我们的差异化在迁移成本:一个已经在用 Claude Code 的开发者已经有 `CLAUDE.md`,他应该能在不改任何文件名的情况下试用 `hcode`。代价是我们的指令面有一部分由另一个产品的约定定义,所以这个回退是**兼容桥,不是我们的正典格式**。

## 后果

- **`CLAUDE.md` 对我们只读。** 永不写入。一个会去改另一个 agent 指令的工具,是没人要求过的惊吓。
- **往回退列表里追加是安全的,重排不是。** `HCODE.md` 优先是所有已经写了这个文件的人的承诺,以后再改就是破坏性变更。
- 启动时点名它用了哪个文件,所以同时持有两份的仓库永远不会靠猜。
